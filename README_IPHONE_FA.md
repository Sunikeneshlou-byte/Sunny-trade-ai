# Sunny Trade AI — نسخه آیفون 0.2

این نسخه یک **PWA موبایلی** است: بعد از قرار گرفتن روی یک آدرس HTTPS، در Safari باز می‌شود و می‌توان آن را با Share → Add to Home Screen مثل اپ روی آیفون نصب کرد.

## امکانات فعلی
- رابط فارسی مخصوص آیفون و لمس
- اسکن ۸ بازار: BTC, ETH, SOL, XRP, ADA, DOGE, LINK, AVAX در برابر USD
- تلاش برای دریافت کندل‌های ۱ ساعته عمومی Coinbase Exchange مستقیماً از مرورگر
- محاسبه EMA20/50، RSI14، MACD ساده، ATR و نسبت حجم
- سیگنال قواعدی: «بررسی خرید / صبر / ریسک بالا»
- Paper Trading با موجودی مجازی، کارمزد و لغزش فرضی
- حد سود و حد ضرر آزمایشی؛ هنگام هر اسکن بازار بررسی می‌شوند
- ذخیره معاملات و تنظیمات در LocalStorage همان گوشی
- قابلیت PWA و کش فایل‌های رابط برای بازشدن بهتر

## نکته مهم درباره داده Live
اگر Safari نتواند به API عمومی Coinbase متصل شود، برنامه برای اینکه رابط از کار نیفتد، آن بازار را با برچسب واضح `Demo fallback` نمایش می‌دهد. هیچ داده ساختگی به‌جای داده زنده پنهان نمی‌شود.

## محدودیت‌های نسخه 0.2
- هنوز معامله واقعی، کیف پول، DEX/CEX، API Key، خبر، Order Book، مدل ML آموزش‌دیده، بک‌تست حرفه‌ای و اعلان پس‌زمینه ندارد.
- تحلیل فعلی قواعد فنی ساده است و «احتمال برد» نیست.
- حد سود/ضرر فقط وقتی بازار دوباره اسکن می‌شود بررسی می‌شود؛ مانیتورینگ 24/7 سروری هنوز اضافه نشده.
- داده فعلی USD است، نه USDT.
- داده و تاریخچه Paper Trading روی همان مرورگر/گوشی ذخیره می‌شوند؛ پاک‌کردن Website Data می‌تواند آن‌ها را حذف کند.

## نصب واقعی روی آیفون
برای Add to Home Screen باید این پوشه روی HTTPS میزبانی شود. این ZIP به‌تنهایی اپ App Store نیست. مرحله بعد، انتشار همین پوشه روی یک میزبان HTTPS است.

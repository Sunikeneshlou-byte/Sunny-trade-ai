# Sunny Trade AI — نسخه ۸ (آزمایشی)

## نصب
فایل ZIP را در Files آیفون باز کنید. فایل‌های **index.html، app.js، styles.css، service-worker.js، manifest.webmanifest، icon-192.png، icon-512.png** را در شاخه اصلی مخزن GitHub قبلی بارگذاری کنید و تغییرات را Commit کنید. فایل **test_v8.js** و README لازم نیست روی سایت بارگذاری شوند. GitHub Pages را روی main/root نگه دارید. سایت: https://sunikeneshlou-byte.github.io/Sunny-trade-ai/

قبل از انتشار بهتر است در نسخه فعلی قسمت تنظیمات روی «دانلود نسخه پشتیبان معاملات» بزنید. نسخه ۸ کلید ذخیره‌سازی نسخه ۶ را حفظ کرده است؛ اگر حافظه Safari پاک شود، بدون فایل پشتیبان اطلاعات از بین می‌روند.

## قابلیت‌ها
- انتخاب حداکثر ۱۰۰ نماد دلاری و تحلیل اولیه کندل ۱۵ دقیقه‌ای، تحلیل بیشتر تا ۳۵ نماد روی داده‌های ۵ دقیقه و یک ساعت و تا ۱۵ نماد روی داده‌های یک دقیقه و روزانه.
- حداکثر ۲۵ نماد دارای شرایط اولیه برای خرید، با مدت‌های ۵ دقیقه، ۲۰ دقیقه، ۴ ساعت، ۲۴ ساعت و ۳۰ روز. این مدت‌ها **افق آزمایشی** هستند، نه پیش‌بینی زمان سود.
- زیر کارت هر ارز: خرید یا صبر، مدت انتخاب‌شده، قیمت مرجع کندل بسته، SL/TP، سطح ریسک، سناریوی سود و زیان دلاری پس از هزینه‌های فرضی و علت انتخاب.
- محدودیت ورودی کمتر از ۵ دلار و بالاتر از سقف تنظیم‌شده، عدم خرید همزمان مجدد نماد، دریافت قیمت تازه قبل از خرید و فروش آزمایشی.
- ثبت دلیل خروج، قیمت واقعی محاسبه‌شده خروج شبیه‌سازی، قیمت فعال‌کننده (در صورت وجود)، زمان خروج و تأخیر.
- پشتیبان‌گیری و بازیابی JSON با سازگاری داده‌های نسخه ۶.

## محدودیت‌های مهم
این یک ابزار الگوریتمی روی مرورگر و صرفاً Paper Trading است. **به سرویس هوش مصنوعی، صرافی برای اجرای معامله، سرور ۲۴ ساعته و سرویس اعلان متصل نیست.** مدل تحلیل ساده و آزمون تاریخی گسترده نشده است. تنها داده کندل‌های بسته را تحلیل می‌کند؛ سیگنال خرید توصیه مالی نیست. اجرای خروج در زمان مشخص، قیمت SL یا TP تضمین نمی‌شود؛ Safari باید فعال، آنلاین باشد و داده تازه دریافت کند.

API Coinbase ممکن است بعضی ارزها را نداشته باشد یا محدودیت درخواست بدهد؛ بنابراین کمتر از ۱۰۰ نماد معتبر و کمتر از ۲۵ فرصت قابل نمایش است. تحلیل یک ماهه فقط برای بخشی از فهرست‌های منتخب داده روزانه می‌گیرد، نه تمام ۱۰۰ نماد. ابزار SHORT واقعی یا فروش استقراضی **ندارد**: بستن یک خرید آزمایشی SELL واقعی یا Short نیست.

## آزمون انجام‌شده
JavaScript syntax، شاخص‌های نمونه، سناریوهای کارمزد، فرمت نماد، قواعد ورود، سازگاری داده و ساختار فایل بررسی شده‌اند. آزمایش واقعی مرورگر Safari و API در دستگاه شما هنوز لازم است.

## اصلاح مهم نسخه ۸
- فرصت خرید فقط زمانی انتخاب می‌شود که پس از کارمزد و لغزش فرضی، سود خالص سناریوی هدف مثبت، زیان سناریوی حد ضرر منفی و نسبت سود خالص به قدر مطلق زیان خالص حداقل ۱٫۵ باشد.
- اگر فرصت‌های واجد شرایط کمتر از ۲۵ مورد باشند، فقط همان تعداد نشان داده می‌شود. هیچ فرصتی برای پرکردن عدد ۲۵ اضافه نمی‌شود.
- در کارت هر ارز نسبت سود/ضرر خالص نمایش داده می‌شود؛ با تغییر کارمزد و لغزش در تنظیمات، انتخاب‌ها در رندر بعدی دوباره ارزیابی می‌شوند.
- تأییدها فقط تحلیل الگوریتمی روی کندل‌های بسته‌شده و بازه‌های در دسترس هستند؛ نه پیش‌بینی سود و نه تأیید مستقل کیفیت استراتژی.
- این نسخه سرور ۲۴ ساعته و اتصال مدل هوش مصنوعی خارجی ندارد؛ فقط پول مجازی.

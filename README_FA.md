# Sunny Trade AI v6 — نسخه آزمایشی آیفون

**وضعیت: نسخه مهندسی و Paper Trading. نه ربات معامله واقعی، نه AI متصل، نه سود تضمینی.**

## امکانات
- اسکن حداکثر ۱۰۰ بازار دلاری موجود در Coinbase Exchange (تا حد ظرفیت و دسترسی API)، با چهار درخواست هم‌زمان.
- نمایش حداکثر ۲۵ گزینه برتر اسکن شده برای بررسی؛ این عدد به معنی ۲۵ سیگنال سودآور نیست. برای جستجوی مستقل، نماد را وارد و دکمه دریافت مستقل را بزنید.
- فیلتر اولیه با داده کندل بسته‌شده، شاخص‌های RSI، EMA، MACD ساده، ATR و حجم تخمینی، همراه با نمودار شمعی.
- قیمت کوچک با اعشار مناسب؛ محاسبه سود و ضرر دلاری با کارمزد و لغزش **فرضی**.
- معاملات آزمایشی Spot با دریافت قیمت عمومی تازه پیش از ثبت، حد سود/ضرر و زمان پایان آزمایشی.
- دریافت مستقل قیمت همه معاملات باز، حتی اگر خارج از فهرست رتبه‌بندی باشند؛ خطای دریافت قیمت باعث توقف خروج و نمایش وضعیت نامشخص می‌شود.
- پشتیبان‌گیری JSON و بازیابی محدود با کنترل‌های اعتبارسنجی.
- حالت نصب به Home Screen در آیفون پس از انتشار HTTPS.

## محدودیت‌های ضروری
- بدون سرور، هنگامی که Safari بسته یا گوشی قفل است هیچ پایش مستمر، اعلان یا اجرای خودکار تضمین‌شده‌ای وجود ندارد.
- API عمومی ممکن است از دسترس خارج شود، درخواست‌ها را محدود کند یا برای برخی نمادها داده ناکافی برگرداند. ۱۰۰ بازار **سقف اسکن** است، نه تضمین داده معتبر ۱۰۰ بازار.
- قیمت لحظه‌ای نقل‌شده و کندل بسته‌شده دو چیز متفاوت‌اند. اجرای مجازی نیز نمی‌تواند لغزش واقعی، ترتیب سفارش یا نقدشوندگی دفتر سفارش را بازسازی دقیق کند.
- انتخاب ۲۵ مورد صرفاً بر اساس امتیاز فنی و شروط اولیه است؛ مدل AI آموزش‌دیده، تحلیل اخبار، بک‌تست بدون سوگیری و تأیید سودآوری هنوز وجود ندارند.
- این نسخه به صرافی یا کیف پول واقعی وصل نیست و نباید با پول واقعی استفاده شود.
- برای هشدار دائمی، دیتابیس سروری، موتور زمان‌بندی و Web Push به فاز جداگانه نیاز داریم.

## نصب و به‌روزرسانی
۱. ابتدا از نسخه قبلی در بخش تنظیمات برنامه **دانلود نسخه پشتیبان معاملات** بگیرید و آن را در Files ذخیره کنید.
۲. فایل‌های ZIP را از حالت فشرده خارج کنید و فایل‌های اصلی (index.html, app.js, styles.css, service-worker.js, manifest.webmanifest و آیکون‌ها) را در ریشه مخزن GitHub قرار دهید، نه داخل یک پوشه فرعی.
۳. به GitHub Pages فرصت دهید انتشار جدید را کامل کند. Safari را بازآوری کنید؛ حافظه سرویس‌ورکر ممکن است چند لحظه نسخه قدیمی را نگه دارد.
۴. بعد از صحت عملکرد، از Share > Add to Home Screen برای نصب وب‌اپ استفاده کنید.
۵. تا پایان تست‌های خودتان هیچ معامله‌ای را به‌عنوان توصیه مالی در نظر نگیرید.

## تست‌ها
- `node --check app.js`
- `node test.js` (۱۱ آزمون محاسباتی/ساختاری)
- `python validate.py` (تطابق شناسه‌ها، manifest و فایل‌های PWA)

تست اجرای مرورگر در این محیط به علت مسدود بودن دسترسی localhost انجام نشد؛ تست عملی روی Safari هنوز لازم است.

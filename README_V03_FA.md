# Sunny Trade AI 0.3 — نسخه آیفون

نسخه آزمایشی وب‌اپ، بدون پول واقعی و بدون حساب صرافی.

## نصب نسخه جدید
در مخزن GitHub همان ۳ فایل `index.html`، `app.js` و `styles.css` و فایل `service-worker.js` را با نسخه‌های جدید جایگزین کنید. دیگر فایل‌ها تغییری نکرده‌اند. پس از انتشار GitHub Pages، Safari را باز و یک بار رفرش کنید. ممکن است کش نسخه قدیمی را نگه دارد؛ از مرورگر private برای مقایسه استفاده کنید. داده‌های معاملات آزمایشی قبلی با کلید ذخیره‌سازی قبلی حفظ می‌شوند؛ قبل از هر تغییر مهم از وضعیت و تاریخچه عکس بگیرید.

## امکانات
- دریافت فهرست بازارهای فعال USD از Coinbase Exchange و انتخاب تا ۴۰ بازار (اگر فهرست در دسترس نبود همان ۸ نماد اولیه)
- دریافت کندل واقعی بسته‌شده در بازه‌های ۱، ۵، ۱۵ و ۶۰ دقیقه، ۶ ساعت و ۱ روز؛ بازار فاقد داده با قیمت ساختگی جایگزین نمی‌شود
- نمودار شمعی فشرده SVG در کارت هر بازار و صفحه خرید آزمایشی
- جست‌وجو، فیلتر سیگنال و رتبه‌بندی اولیه بر اساس امتیاز اندیکاتور
- RSI و ATR استاندارد تقریبی با هموارسازی Wilder؛ EMA با دوره آماده‌سازی اولیه
- معامله آزمایشی شامل کارمزد فرضی و لغزش، حد سود/ضرر آزمایشی

## محدودیت مهم
- این نسخه یک مدل AI آموزش‌دیده، الگوریتم پیش‌بینی تضمینی یا ربات معامله ۲۴ساعته نیست.
- برچسب «سیگنال خرید ضعیف» برابر با احتمال ضرر بالا نیست.
- حد سود/ضرر فقط وقتی برنامه باز است و اسکن اجرا می‌شود بررسی می‌شود، نه در پس‌زمینه.
- انتخاب بازار بر اساس فیلد حجم ارسالی API انجام می‌شود و ممکن است برای برخی بازارها ناکامل باشد؛ این مورد باید در نسخه سروری بهبود یابد.
- API عمومی ممکن است از طریق محدودیت درخواست، سرعت یا اینترنت در دسترس نباشد.
- معاملات آزمایشی فقط با قیمت آخرین کندل بسته‌شده انجام می‌شوند؛ نتیجه با اجرای واقعی متفاوت است.
- تا قبل از اعتبارسنجی مستقل و فورواردتست، هیچ سیگنالی برای پول واقعی مناسب نیست.


## افزوده نسخه 0.3.1
در فرم خرید آزمایشی، مبلغ دلاری باقی‌مانده در حد سود و حد ضرر و سود/زیان خالص به دلار با احتساب کارمزد و لغزش فرضی نمایش داده می‌شود. این خروجی احتمال موفقیت یا تضمین نتیجه نیست.
